# 个人维护需求

## 核心需求

2026-09-20 确认，2026-09-22 更新。

- 核心场景是查看 OpenAI、Kimi 的订阅用量。点击菜单栏即可查看，减少每次打开各家网页查询的操作。
- Cursor 当前不属于核心需求；相关改动按实际收益评估，不作为核心订阅查询优先处理。
- 使用程度很轻，偏好应用维持轻量、简单，不主动增加复杂功能。轻量是使用体验偏好，尚未指定内存、CPU 或包体积指标。
- 自行维护的起因是旧版本 Kimi 订阅查询失效，用户怀疑与 Kimi 网页变化有关。原因和当前版本状态留到正式维护时验证；初始化不要求诊断或修复。
- 其他供应商及未讨论的功能仍为未知，不能据此认定用户不需要。多账号、提醒等尚未确认为需求。

## 上游更新取舍

优先考虑核心订阅查询的可用性，以及相关稳定性和安全修复。结合行为、依赖及底层变化对实际使用的影响给出接收范围建议和理由，不能只按供应商或功能名称筛选。其他功能按实际收益建议取舍，由用户决定接收范围。

# 个人维护需求

## 已确认的选择

2026-09-09，用户确认以当前本地代码建立自用维护版本。尚未指定重点供应商、具体功能需求或已知不满，后续想法经用户确认后再记录为要求。

- 沿用现有 fork。`origin` 是 `allgemeiner-intellekt/CodexBar`，`upstream` 是 `steipete/CodexBar`。
- 功能修改使用短期 `codex/` 分支；初始化保留当前 `main`。提交与推送按任务授权处理。
- 用户明确要求接收外部改动时再同步，先评估行为、依赖、稳定性及兼容性。保留本地修改，不自动重置工作区。
- 保留 `AGENTS.md` 的格式、测试隔离、供应商数据隔离和并发安全约束。优先使用现有 SwiftPM 和仓库脚本。
- 默认将全量测试与 release 打包交给 GitHub Actions macOS runner，本机只做低并发增量构建、针对性测试及安装验证。文档和工作流准备仅做静态检查。
- 使用 release 临时签名构建，安装到 `/Applications/CodexBar.app`。沿用应用标识和设置位置，接受官方自动更新关闭及 iCloud 同步不可用。
- 开发完成不自动安装或重启。用户要求本地安装或更新时使用 [local-install](../local-install/SKILL.md)。登录项不自动开启。
- 公开发行流程只在明确要求公开发行时使用，不调用原维护者的签名、发布或 Homebrew 凭据。
